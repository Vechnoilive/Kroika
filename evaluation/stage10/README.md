# Evaluation-набор этапа 10

`manifest.json` и 50 PNG создаются детерминированно командой
`python scripts/generate_stage10_dataset.py`. Изображения — простые собственные
синтетические схемы под CC0-1.0; они подходят для проверки адаптеров и метрик, но не
доказывают качество на фотографиях реальной одежды.

Ответы сохраняются отдельно как `results/<provider>/<case_id>.json`. Допустим либо
чистый `AIStyleAnalysis`, либо объект `{analysis, latency_ms, cost_usd}`. Сравнение:

```bash
python scripts/evaluate_stage10.py
```

Оценщик считает валидность JSON/семантики, точность по признакам, полноту уточняющих
вопросов, Brier score уверенности, медианную задержку и среднюю стоимость. Выбор
реального default заблокирован, пока не будет минимум 50 одинаковых реальных примеров
со статусом `expert_verified`, разрешением на использование и ответами обоих сервисов.
