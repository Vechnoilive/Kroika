# Kroika

Русскоязычное веб-приложение для закройщика: ручные женские мерки + подтверждённое описание фасона → детерминированная векторная выкройка в миллиметрах → SVG и A4 PDF 1:1.

**Реализована автоматическая часть этапа 9 из 15: припуски по типам срезов, линии шва/среза, единый SVG и диагностический PDF A4 1:1. Физическая печать на двух принтерах и проверка макета ожидаются.**

Пользователь поручил выбрать рабочие ответы вместо интервью. Они оформлены как решения разработчика, без фиктивного согласования тётей. Для исследовательского прототипа выбран `kroika-gc-woven 0.1.0` на основе зафиксированного открытого GarmentCode; статус `experimental`.

## Что сделано

- Перенесены требования, сценарий, словарь и дорожная карта этапа 1.
- Сопоставлены подходы и определён источник вычислительных блоков с точной версией и MIT-уведомлением.
- Записаны 41 скалярная формула, единицы, коэффициенты и 3 синтетических профиля с 123 контрольными значениями.
- Подготовлены пробные прибавки/припуски, критерии точности и проверка расчётов без внешних зависимостей.
- Выполнен отдельный запуск 12 исходных геометрических заготовок; измерены реальные длины интерфейсов и записаны несогласованные соединения.
- Определены семь основных сущностей проекта, 13 JSON Schema 2020-12 и OpenAPI 3.1 с 18 реализованными операциями.
- Добавлены независимые интерфейсы AI/Pattern Engine, стабильный hash входов, смысловые проверки и безопасный реестр миграций.
- Собран адаптивный React-интерфейс: один активный шаг, крупные действия, понятные ошибки, восстановление последнего проекта и явная маркировка учебного режима.
- Реализован FastAPI backend, ревизии проектов в SQLite, идемпотентные результаты генерации, безопасное логирование и health checks.
- Добавлены offline mock-AI, отдельный чистый пакет `pattern-engine`, Docker Compose и запуск одной командой без Docker.
- Добавлен каталог из 37 линейных и угловых мерок для текущих и запланированных изделий, с диапазонами и нейтральными инструкциями.
- Мастер показывает одну мерку за раз, поддерживает cm/mm, схемы, черновики, проверки и явное происхождение каждого нового значения.
- Отдельные профили сохраняются только по выбору пользователя, имеют ревизии и могут повторно использоваться; новый проект всегда начинается без подставленных мерок.
- Реализованы точки, векторы, линии, эллиптические дуги, кубические Безье и связные контуры в миллиметрах на IEEE-754 binary64.
- Добавлены длины, площадь, границы, пересечения, offset, трансформации, топологические проверки и канонический JSON.
- Ядро блокирует вырожденные, неоднозначные и самопересекающиеся результаты стабильной ошибкой вместо скрытого исправления.
- F01–F41 перенесены в исполняемый модуль; прибавки применяются к обхватам один раз с явным распределением перед/спинка.
- Построены четыре базовые детали лифа и юбки с вытачками, проймой, круглой горловиной, долевыми и контрольными линиями.
- Добавлен отдельный одношовный рукав: высота оката решается по фактической суммарной длине проймы.
- Контрольные размеры S/M/L, schema-проверка и 60 property-based масштабов подтверждают вычислительную повторяемость.
- Собраны 6 деталей платья/сарафана: лиф, юбка и объединённые обтачки переда и спинки.
- Записаны 10 явных пар швов, контрольные метки, долевые и инструкции кроя.
- Поддерживаются 4 сочетания «платье/сарафан × fitted/semi_fitted»; остальные варианты блокируются до геометрии.
- Добавлен безопасный SVG-предпросмотр и последовательный экран результата для пользователя.
- Для каждого исходного сегмента назначается явный тип припуска: обычный шов, горловина, пройма, молния, низ, низ рукава или сгиб.
- Все 6 линий среза строятся fail-closed: самопересечение или неполный набор припусков останавливают результат.
- Единый SVG содержит линии шва/среза, долевые, сгибы, надсечки, подписи и квадрат 50×50 мм.
- Диагностический PDF делит выкройку на A4 в масштабе 1:1, добавляет карту листов, 10-мм поля/нахлёст и метки совмещения.
- Экран результата объясняет печать в три шага и отдельно предупреждает, что раскрой ткани пока запрещён.

Это ещё не готовое лекало для раскроя ткани. Цифровая разметка и пробная печать реализованы, но масштаб нужно физически проверить минимум на двух принтерах, а посадку — на макете и у закройщика. **Исходный gate этапа 2 остаётся BLOCKED.** Успешные численные тесты и PDF не означают проверенную посадку.

## Запустить приложение

Нужны Python 3.12+ и Node.js 24+. Первый запуск сам создаст `.venv`, установит зависимости и откроет браузер.

Windows PowerShell:

```powershell
py -3.12 scripts/start_local.py
```

macOS/Linux:

```bash
python3 scripts/start_local.py
```

После запуска откройте `http://127.0.0.1:5173`. Для остановки нажмите `Ctrl+C`. Подробности: [LOCAL_SETUP.md](docs/LOCAL_SETUP.md).

Вариант с Docker:

```bash
docker compose up --build
```

Интерфейс будет доступен на `http://localhost:8080`, API — на `http://localhost:8000`.

## Проверить текущий этап 9

После первого запуска, Linux/macOS:

```bash
.venv/bin/python scripts/verify_stage9.py
```

Windows PowerShell:

```powershell
.venv\Scripts\python.exe scripts\verify_stage9.py
```

Команда запускает только новые проверки этапа 9: припуски и линии среза, SVG, PDF A4, интерфейс, production-сборку и HTTP smoke-test. Полную историческую регрессию запускает `scripts/verify_all.py` только по отдельному решению пользователя. API-ключи и Docker для проверки не нужны.
