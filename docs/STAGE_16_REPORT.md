# Отчёт этапа 16 — расширенное описание фасона

Дата: 2026-09-22. Версия приложения: `0.16.0`.

## Что реализовано

- `AIStyleAnalysis.design_features` описывает до 24 отдельных элементов фасона, до 6
  слоёв и визуальные пропорции без попытки угадывать сантиметры по фотографии.
- В словарь включены пояса, кушаки, складки, защипы, сборки, воланы, оборки, баски,
  кокетки, панели, накладные слои, драпировки, карманы, застёжки, разрезы, шлицы,
  капюшоны, воротники, манжеты, бретели, вытачки и рельефы.
- Для каждого элемента обязательны расположение, способ соединения, количество,
  симметрия, уверенность, русское описание и визуальное доказательство.
- Новый `GarmentDesignIntent` связывает распознанные признаки только с разрешёнными
  модулями текущего движка. Остальные получают `planned` или `needs_confirmation`.
- UI показывает конструктивный план. Неподдержанная деталь блокирует подтверждение
  точного фасона и последующую генерацию вместо молчаливой потери элемента.
- Старые проекты остаются читаемыми: `design_features` и `design_intent` необязательны
  для ранее сохранённых документов, но обязательны для каждого нового AI-ответа.
- Завершённые шаги стали кнопками. Пользователь может вернуться к эскизу, фасону,
  меркам, ткани, построению или результату; сохранённые данные не удаляются.

## Граница этапа

Этап 16 создаёт прослеживаемый конструктивный план, но не реализует геометрию новых
воланов, складок, поясов-кушаков или накладных слоёв. Это намеренно: пока отсутствует
проверенный модуль этапа 18, приложение показывает блокировку и не выдаёт базовый шаблон
за точное повторение фотографии. Редактирование и разрешение вопросов запланированы на
этап 17.

## Локальная проверка

```bash
.venv/bin/python scripts/verify_stage16.py
```

Команда не запускает тесты прошлых этапов. Она проверяет только:

- 4 backend/schema/semantic теста этапа 16;
- Ruff для изменённых Python-файлов;
- 2 UI-теста конструктивного плана и возврата по шагам;
- TypeScript typecheck;
- production-сборку Vite.

Результат: **PASSED**. Физические `paper/expert/toile` gates не менялись и остаются
`pending`.
