# Словарь проекта

Определения нужны для одинакового понимания требований. Структуры данных закреплены в `schemas/v1`; точки снятия мерок и правила расчёта продолжают проверяться с закройщиком.

| Термин | Значение в проекте |
| --- | --- |
| Мерки тела / BodyMeasurements | Измерения фигуры; не содержат прибавок и припусков |
| Параметры модели | Выбранные размеры и особенности изделия: длина юбки, глубина выреза, ширина бретели и т. п. |
| Прибавка на свободу облегания / wearing ease | Добавка к меркам для выбранной свободы движения и облегания; величина зависит от утверждённой методики и ткани |
| Модельная прибавка / design ease | Дополнительный объём ради силуэта; хранится отдельно от прибавки на свободу |
| Припуск на шов / seam allowance | Расстояние от линии стачивания до среза для обработки края; не увеличивает расчётный готовый обхват изделия |
| Выкройка / лекала | В этом продукте — комплект векторных деталей; наличие припусков всегда указывается явно |
| Базовая основа / блок | Конструкция по меркам и конкретной методике до преобразования в выбранный фасон |
| Методика построения | Согласованная система мерок, формул, правил и прибавок с источником и версией |
| Лиф | Верхняя часть рассматриваемого платья до линии соединения с юбкой |
| Вытачка | Участок, который закрывают при стачивании для формирования объёма; имеет вершину и две стороны |
| Рельеф | Конструктивный шов, разделяющий деталь и участвующий в формировании объёма |
| Пройма | Контур отверстия для руки в лифе |
| Окат | Верхний контур втачного рукава, соединяемый с проймой |
| Посадка по шву / припосадка | Заранее заданная разница длин сопрягаемых швов для сборки без трактовки её как ошибки |
| Баланс | Согласование длин и положения переда/спинки по правилам методики, влияющее на посадку изделия |
| Линия шва / SeamLine | Линия будущего стачивания; по ней сопоставляют длины парных швов |
| Линия среза / CuttingLine | Граница раскроя с учётом выбранных припусков |
| Долевая | Указание ориентации детали относительно направления нитей основы ткани |
| Сгиб | Край детали, который совмещают со сгибом материала, когда это предусмотрено конструкцией |
| Надсечка | Контрольная метка для совмещения деталей при сборке |
| Обтачка | Деталь для обработки соответствующего края; её линии соединения должны согласовываться с основной деталью |
| Макет / toile | Пробное изделие для проверки посадки; результат фиксируется специалистом |
| GarmentSpec | Структурированное описание фасона, независимое от AI-провайдера; предложение AI ещё не является подтверждённым вводом |
| Pattern Engine | Отдельный вычислительный модуль: по подтверждённым входам и версии методики строит геометрию в миллиметрах |
| Каноническая геометрия | Единое представление деталей, из которого получают SVG и PDF |
| Детерминированность | Те же нормализованные входы, версии методики и движка дают ту же геометрию |
| FormulaRecord | Запись о формуле: назначение, входы, единицы, источник, версия, диапазоны, допуски, ручной пример и проверки |
| Инвариант | Проверяемое свойство конструкции, например замкнутость контура или согласованность парных швов |
| confidence | Оценка уверенности модели в признаке; не гарантия правильности и не разрешение на построение |
| uncertainties | Неясные или невидимые особенности, которые требуют ответа пользователя |
| Mock | Явно обозначенный тестовый анализатор с подготовленными ответами, без реального вызова AI |
| SVG | Векторный формат предпросмотра и цельной выкройки; для 1:1 физические размеры задаются в mm |
| A4 PDF 1:1 | PDF с физическими страницами 210 × 297 мм, где размеры лекала сохраняются при печати 100% |
| Нахлёст / overlap | Общий участок соседних печатных листов для их совмещения |
| blocking_error | Ошибка, запрещающая производственный экспорт |
| warning / info | Предупреждение / пояснение; их правила задаются явно, они не скрывают блокирующие ошибки |
| experimental | Методика или модуль находятся на стадии исследования; производственная готовность не подтверждена |
| expert_reviewed | Есть зафиксированная проверка специалистом; сама по себе не означает проверку макетом |
| toile_verified | Есть документированная бумажная проверка и примерка макета в указанной области применимости |
| Gate этапа | Условие завершения этапа: PASSED при наличии подтверждающих результатов, иначе BLOCKED с причиной |
| schema_version | Версия структуры JSON; меняется независимо от версии методики и ревизии проекта |
| revision | Номер последовательного сохранения конкретного проекта; защищает от случайной перезаписи |
| input_hash | SHA-256 нормализованных вычислительных входов и версии методики для повторяемой генерации |
| semantic validation | Проверка отношений между уже корректными полями: суммы долей, дуги и обхваты, область метода, связи ID/hash |

Смежные понятия нельзя объединять в одно поле: **мерка тела → прибавка на свободу → модельная прибавка → припуск** имеют разные назначения. Точное правило их применения к полным и частичным обхватам принадлежит выбранной методике, а не этому словарю.
