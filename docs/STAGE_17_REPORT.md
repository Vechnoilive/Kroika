# Отчёт этапа 17 — редактор конструктивного плана

Дата: 2026-09-22. Версия приложения: `0.17.0`.

## Что реализовано

- `GarmentDesignIntent` хранит статус ручной проверки, время подтверждения и ответы на
  каждый вопрос модели; старые документы этапа 16 остаются совместимыми.
- Для каждой детали можно исправить описание, тип, вариант, расположение, способ
  конструкции, количество и четыре размерных параметра в миллиметрах.
- Деталь или дополнительный слой можно исключить как ошибку распознавания, не удаляя
  исходную запись, либо добавить пропущенный элемент вручную.
- Слои, визуальные пропорции и асимметрия подтверждаются отдельно. Проверка требует
  ровно один включённый основной слой и непустой ответ на каждый вопрос.
- Сохранение проверки создаёт обычную ревизию проекта и сбрасывает устаревший результат
  построения. Подтверждение фасона разрешено только после сохранённой проверки.
- Введённые вручную размеры сохраняются, но остаются `planned`, пока отдельный
  геометрический модуль не начнёт применять их к выкройке.
- Исключённые элементы получают `excluded`, не участвуют в вычислении готовности, но
  остаются прослеживаемыми в проекте.

## Fail-closed правила

Проект нельзя передать движку, если проверка не подтверждена, остались включённые
непроверенные элементы, нет ответа, нарушено число основных слоёв или хотя бы одна
включённая деталь требует ещё не реализованного модуля. UI и semantic validation
проверяют эти условия независимо.

## Автоматический gate этапа

Запускается только набор этапа 17:

```bash
.venv/bin/python scripts/verify_stage17.py
```

Он включает 4 backend-теста, 2 UI-теста, Ruff для изменённого Python-кода,
TypeScript typecheck и production-сборку Vite. Исторические тесты этапов 2–16 в этот
gate не входят.

## Что остаётся дальше

Редактор фиксирует намерение, но не создаёт формулы для воланов, складок, сборок,
произвольных поясов и других новых элементов. Их преобразования, инварианты и эталоны —
задача этапа 18. Бумажные, экспертные и макетные gates остаются открытыми.
