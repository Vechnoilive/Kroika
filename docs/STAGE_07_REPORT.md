# Отчёт этапа 7 — базовые блоки

Дата: 2026-09-14. Версия приложения: 0.7.0. Версия Pattern Engine: 0.3.0.

## Что реализовано

- F01–F41 перенесены в чистый исполняемый модуль с теми же именами выходов и fail-closed проверками.
- Подтверждённые прибавки применяются ровно один раз и сохраняют заданное распределение перед/спинка.
- Построены базовые контуры лифа и юбки: перед, спинка, талиевые и нагрудная вытачки, пройма, круглая горловина, линии груди и бёдер, долевая и контрольные линии.
- Реализован отдельный одношовный рукав с численным согласованием оката по фактической длине проймы.
- Длина плеча стала обязательной меркой для платья и сарафана; примеры и синтетические профили обновлены без скрытых средних.
- Движок выполняет построение и контроли, но не выдаёт основы за готовое изделие: сборка этапа 8 и производственный экспорт остаются заблокированы.

## Проверка

Статус автоматической части: PASSED после GitHub Actions.

Проверяются 123 фиксированных значения, три набора контрольных размеров, четыре замкнутых контура каждого профиля, JSON Schema round-trip, сохранение талии и плеча, 60 property-based масштабов, окат рукава, явные ошибки области и сквозной HTTP smoke-test. Полная регрессия этапов 2–7 запускается командой python scripts/verify_all.py.

## Gate

Автоматический gate этапа 7: PASSED.
