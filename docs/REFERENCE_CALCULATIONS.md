# Три расчётных профиля

**S/M/L — условные идентификаторы синтетических примеров, не размеры одежды.** Никакие реальные мерки тёти или клиентов здесь не использованы. Все значения внутри — mm. Профили проверяют только перечисленные скалярные формулы и не являются тремя полными ручными построениями из gate этапа 2.

## Независимый способ получения чисел

Для удобства проверки заданы `tan(a)=1/5` и `tan(h/2)=1/10`; соответствующие углы 11.309932474020215° и 11.421186274999286°. Подстановка этих дробей позволяет рассчитывать основную таблицу десятичной арифметикой без геометрического движка. Значения независимо посчитаны с Decimal precision=36; стороны треугольных вытачек — по теореме Пифагора. Проверяющая программа использует float64 и тригонометрию и сравнивает с сохранёнными числами, не перезаписывая их.

Прибавки в этих листах равны 0 для аудита исходных блоков; рабочие прибавки изделия находятся отдельно в [FIT_AND_TOLERANCES.md](FIT_AND_TOLERANCES.md).

## Контрольные раскрытые подстановки

- S: половина переда `(840−400)/2=220`; передняя талия `(660−330)/2=165`; её раствор `(220−165)×2/3=110/3 mm`. Заднее уменьшение `200−165=35<40`, поэтому боковое уменьшение 0, две вытачки по 17.5 mm.
- M: поправки переда `(240−190)/5=10`, спинки `(220−190)/5=6`; длины переда `460−10=450`, спинки `410−6=404`, боковой ориентир `404−(240−220)/5=400`; нагрудный раствор `450−400=50 mm`. Независимое сокращение этих же выражений даёт `Lf−Lb=460−410=50`.
- L: четверти бёдер `(1120−580)/2=270` и `580/2=290`; задняя глубина `220×1.05=231`; боковые уменьшения 22 и 23.1; растворы `270−210−22=38` и `290−200−23.1=66.9 mm`. Передняя талия `2×(270−22−38)=420`, задняя `2×(290−23.1−66.9)=400`, сумма 820 mm.

## Выявленная граница метода

В F19 есть скачок при 40 mm: чуть ниже порога боковое уменьшение 0, на пороге — 40/6 mm. Поэтому раствор двух задних вытачек не обязан монотонно расти от S к M. Это воспроизведённая особенность исходника; менять её на «красивую» непрерывную формулу без новой версии и проверки нельзя.

Разница задней глубины юбки составляет 9.5 / 10 / 11 mm. Это **не измеренная посадка бокового шва**. Она требует проверки реальных кривых, а не объявления всех швов согласованными по этой таблице.

Команда: `python3 scripts/verify_stage2.py`. Сохранённые числа: [control-examples.json](../references/stage2/control-examples.json). Проверка полного лекала и экспертная подпись: **отсутствуют**.
