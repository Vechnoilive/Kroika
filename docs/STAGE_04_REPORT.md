# Этап 4 — каркас приложения и локальный запуск

Дата: 2026-09-14. Версия приложения: `0.4.0`.

## Результат

- Создан адаптивный React 19 + TypeScript + Vite frontend без внешних шрифтов и runtime-CDN.
- Интерфейс ведёт пользователя по одному активному шагу, сохраняет последний проект, объясняет учебный режим и не выдаёт будущие функции за готовые.
- Создан FastAPI backend с русскими безопасными ошибками, request ID, CORS для локального UI и логами без тел запросов.
- SQLite хранит versioned-проекты, использует WAL, транзакции и `If-Match` для защиты от перезаписи из другой вкладки.
- Генерация идемпотентна по паре `project_id + input_hash`: повтор не создаёт новую запись истории и не раскрывает данные другого проекта.
- Реализован `MockAIProvider`, принимающий только AI-контракт без мерок.
- Создан отдельный чистый пакет `kroika-pattern-engine`. До этапа 6 он fail-closed: возвращает валидный блокирующий отчёт и `pattern: null`.
- Добавлены health checks, `.env.example`, Docker Compose, Dockerfiles, nginx proxy и кроссплатформенный запуск одной командой.

## Проверка

- этап 2: 15 тестов;
- этап 3: 25 контрактных тестов;
- backend этапа 4: 13 тестов;
- frontend этапа 4: 4 теста;
- TypeScript и production build Vite;
- smoke-test: health → SQLite → проект → mock → идемпотентный fail-closed engine → validation/export policy.

Все проверки проходят. OpenAPI валидируется и совпадает с runtime-маршрутами. Compose разобран как YAML, оба сервиса имеют health check, frontend ждёт готовности backend.

## Gate

**Gate этапа 4: PASSED.** Локальный режим поднимается командой `python scripts/start_local.py`; альтернативный контейнерный режим описан командой `docker compose up --build`; smoke-test проходит.

Docker daemon отсутствует в среде разработки, поэтому реальный запуск контейнеров здесь не выполнялся. Dockerfiles и Compose проверены статически, а тот же backend/frontend стек фактически установлен, собран и запущен локально.

Это рабочий каркас, но ещё не приложение для пошива. Настоящие мерки, геометрия, SVG/PDF и Qwen относятся к этапам 5–10. Экспертный gate методики этапа 2 остаётся открытым.
