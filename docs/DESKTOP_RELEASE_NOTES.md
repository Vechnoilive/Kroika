Кройка 0.3.1 для Windows 10/11 x64. Скачайте `Kroika-0.3.1-windows-x64-setup.exe`, закройте прежнее окно и установите обновление поверх старой версии.

На экране фотографий появилась кнопка **«Подключить Gemini»**. Нажмите её, вставьте собственный API-ключ и примените настройки. Gemini станет выбранным сервисом; после закрытия настроек можно открыть 1–4 фотографии, указать перед/спинку, подтвердить отправку и запустить анализ. В окне подключения есть ссылка на получение ключа в Google AI Studio.

Gemini отображается при первом запуске приложения. Исправлена подсказка для ошибок ключа: изменять переменные окружения и перезапускать приложение не нужно. При изменении настроек соединение проверяется заново, для отправки фотографий нужно вновь подтвердить согласие; текущий запрос и выбранные снимки сохраняются.

В сборку включена поддержка SOCKS-прокси, отсутствие которой могло приводить к ошибке запроса ещё до обращения к Google. Дополнительно проверены в установленном exe: ввод ключа через native bridge, системное сохранение и загрузка после перезапуска Windows, настоящий HTTPS-транспорт с проверкой сертификата и отправка изображений переда/спинки. Для этой автоматической проверки используется локальный тестовый сервер, отвечающий в формате Gemini; пользовательские ключи и Google-квота не используются. Живой ответ Google зависит от собственного ключа, доступа проекта и доступности API.

Python, Node.js и исходники для запуска не нужны. WebView2 устанавливается при необходимости из включённого полного установщика Microsoft. Для Gemini нужен интернет и собственный API-ключ: задайте их в «Настройках приложения».

Сохранены анализ фотографий переда/спинки, проверка деталей, мерки, модули построения, редактор, история, PDF A4, SVG, JSON и журнал физических проверок. Геометрические проверки не заменяют примерку.

Проекты, фотографии, ключ и профиль окна хранятся отдельно от программы. Обновление и удаление приложения не удаляют пользовательские данные. Перед сменой версии создаётся проверенная резервная копия базы и фотографий. Чтобы обновиться, сохраните проект, закройте Кройку и запустите новый установщик.

`portable.zip` содержит готовую папку приложения; распаковывайте её целиком. WebView2 должен быть установлен. `SHA256SUMS.txt` содержит контрольные суммы setup и zip. Сборка проверяется на Windows: установка, построение и экспорты, настоящий WebView2/React/native bridge, переустановка и удаление без Python/Node в PATH.

Собственного сертификата подписи издателя нет; Windows может показывать предупреждение SmartScreen. Вложенный установщик WebView2 имеет проверенную подпись Microsoft.
