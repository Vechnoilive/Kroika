# Этап 11 — полный сценарий и редактор

## Что реализовано

- Семь последовательных экранов: проект → изображения → подтверждение фасона → мерки →
  ткань/прибавки/припуски → построение → просмотр и экспорт.
- Результат Qwen или mock сохраняется вместе с проектом, но не становится параметрами
  выкройки без отдельного подтверждения человеком.
- Поддерживается загрузка 1–4 изображений. В интерфейсе доступны Qwen и локальный mock;
  Gemini по продуктовому решению выключен через `KROIKA_ENABLED_AI_PROVIDERS`.
- Редактор меняет только поддержанные формульной моделью параметры и безопасные числовые
  диапазоны. Свободного перемещения точек SVG нет.
- Прибавки на свободу и припуски на швы показаны раздельно. Текущий модуль принимает
  только стабильную тканую ткань с растяжимостью не выше 5%.
- SQLite хранит снимок каждой ревизии и понятную причину изменения. Восстановление старой
  версии создаёт новый черновик; существующие поколения не удаляются.
- Изменение входов отвязывает только устаревший `latest_generation`. Если пользователь
  вернул прежние входы, неизменяемый результат по hash безопасно подключается снова.
- Предпросмотр SVG имеет восемь переключаемых слоёв и масштаб 50–180%. Единый SVG и PDF
  всегда формируются полными из той же канонической геометрии.

## Проверки только этого этапа

`python scripts/verify_stage11.py` запускает:

1. `tests/test_stage11_workflow.py` — история, восстановление, инвалидация результата,
   Qwen-only выдача, SVG-слои и точное соответствие OpenAPI.
2. Два новых frontend-набора — подтверждение фасона, ткань/прибавки, история и preview.
3. Production-сборку frontend.
4. Playwright Chromium E2E полного mock-сценария.
5. Тот же live Qwen E2E, только когда заданы `QWEN_API_KEY` и `QWEN_BASE_URL`.

Тесты этапов 3–10 и `verify_all.py` этой командой не запускаются.

## Честный статус gate

Mock E2E можно полностью автоматизировать в CI. Live Qwen нельзя считать пройденным без
настоящего серверного ключа и регионального endpoint: подготовленный тест помечается
пропущенным, а не заменяется фиктивным HTTP-ответом. Поэтому полное условие этапа 11
остаётся `AWAITING QWEN LIVE E2E`, пока владелец окружения не выполнит эту проверку.

Отдельно остаются открыты физическая печать на двух принтерах и проверка макета
закройщиком. Экспорт по-прежнему диагностический и не разрешает раскрой ткани.
