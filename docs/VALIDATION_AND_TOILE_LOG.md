## Что остаётся до исходного gate этапа 2

1. Довести **все** формулы и геометрические правила выбранного первого блока до полной спецификации: горловина, пройма, закрытие вытачек, действительные линии талии и боковых швов.
2. Уточнить ручные точки измерения и сравнить их с определениями источника.
3. Получить три независимых полных контрольных построения, проверить их на бумаге, оформить автора и дату. Три скалярных расчётных листа этот пункт не закрывают.
4. Подписать расчёты специалистом. Полный gate исходного задания остаётся **BLOCKED**; разработка исследовательской спецификации по поручению пользователя может продолжаться без заявления производственной готовности.

Не назначать `expert_reviewed` или `toile_verified` из успешного арифметического теста. Формальный контракт данных на этапе 3 можно обсуждать отдельно; в этом запуске он не реализуется. Запрет исходного плана на производственное построение по непроверенным формулам сохраняется.
