# Отчёт этапа 23 — рабочее место фото и диагностика AI

Дата: 2026-09-23. Версии frontend/backend: `0.23.0`; геометрический движок остаётся
`kroika-geometry 0.12.0`, потому что формулы и каноническая геометрия не менялись.

## Что реализовано

- Для 1–4 изображений показываются миниатюры, имя, порядок и подписанный вид:
  спереди, сзади, сбоку, крупная деталь, плоский эскиз или другой вид.
- Изображения можно переставить, удалить и повернуть на 90°. После изменения уже
  загруженная локальная копия сбрасывается, чтобы модель не получила старую ориентацию.
- Подписи передаются провайдеру только как порядковые номера и безопасные enum-значения;
  локальные `image_ref`, `project_id`, мерки и координаты в prompt не попадают.
- После успешной локальной загрузки `image_ref` остаётся в состоянии формы. Таймаут,
  отмена или невалидный ответ модели можно повторить без дублирования файла.
- Долгий запрос показывает фазу, прошедшие секунды и кнопку отмены. Ошибки различают
  таймаут, лимит, авторизацию, баланс, недоступность и невалидный ответ; request ID
  остаётся видимым для диагностики.
- Явная кнопка проверки провайдера отправляет минимальный текстовый запрос без фото и
  показывает модель и задержку. Проверка не запускается автоматически и может расходовать
  лимит API, о чём интерфейс предупреждает заранее.
- Добавлен `POST /api/v1/ai/providers/{provider_id}/check`; OpenAPI и общий порт AI
  обновлены без раскрытия ключей.

## Проверка этапа

```bash
.venv/bin/python scripts/verify_stage23.py
```

Gate запускает только проверки этапа 23:

- 4 Python-теста подписей видов, приватности prompt, text-only probe, API и OpenAPI;
- 3 UI-теста превью/порядка, диагностики, повторного использования загрузок и отмены;
- Ruff для изменённого Python-кода;
- TypeScript typecheck;
- production-сборку Vite.

Live-запрос с пользовательским ключом автоматический gate не выполняет. Кнопку проверки
и анализ реального фото запускает только владелец локального приложения.

## Оставшиеся ограничения

Отмена прекращает ожидание браузера и отменяет текущий HTTP-запрос, но внешний сервис
мог уже принять работу до разрыва соединения. Загруженные ссылки переиспользуются в
текущем открытом шаге; полноценное восстановление очереди после перезапуска приложения
остаётся отдельной задачей. Реальное качество фасона по-прежнему требует A/B-набора и
оценки конструктора, а посадка — печати и макетов.
