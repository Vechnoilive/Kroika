# Прибавки, припуски и допуски — рабочие решения

Версия 0.1.0, `experimental`. Значения **выбраны разработчиком по поручению пользователя** для первого испытания, а не получены от тёти и не названы таблицами Aldrich/Мюллера/GarmentCode. Все доступны для явного изменения с повторной проверкой. Материал первого макета — стабильная неэластичная хлопчатобумажная ткань; свойства финальной ткани проверяются отдельно.

## Прибавки на полный обхват, mm

| Пресет | Грудь | Талия | Бёдра | Верх руки при рукаве | Модельная прибавка |
| --- | --- | --- | --- | --- | --- |
| `woven_fitted_trial` | 40 | 20 | 40 | 40 | 0 до явного выбора фасона |
| `woven_semi_fitted_trial` — первый образец | 60 | 40 | 60 | 50 | 0 до явного выбора фасона |
| `reference_zero_ease` — только расчётные листы | 0 | 0 | 0 | 0 | 0 |

Это стартовые величины для проверки, не гарантированно подходящие прибавки для любой ткани/фигуры. Внутри профиля 50% прибавки каждого обхвата назначается передней дуге, 50% задней; доля хранится явно. Прибавка на полный обхват делится между двумя симметричными половинами детали только после такого распределения. Простое равенство «ОГ + прибавка» — целевой размер, его надо проверить на готовом лекале.

Из upstream отдельно взяты **25 мм** добавки к глубине проймы и **20 мм** уменьшения полного плечевого размаха для опорной линии рукава. Это именованные константы конструкции, не изменения снятых мерок. Они остаются экспериментальными. Не добавлять 25 мм второй раз, если пользователь вводит уже конструктивную глубину.

Для длинного рукава без раскрывающейся застёжки нельзя ориентироваться только на запястье: проверить проход кисти. Рабочий минимум отверстия — измеренный обхват кисти + 10 мм; это пробное решение. Полный одношовный рукав ещё не специфицирован.

## Припуски на обработку, mm

| Край | Рабочее значение | Уточнение |
| --- | --- | --- |
| Плечо, бок, талия, соединительный шов | 15 | Первый макет оставляет возможность корректировки |
| Горловина и пройма с обтачкой | 10 | Геометрия обтачки должна точно соответствовать линии притачивания |
| Средний шов спинки под молнию | 20 | Проверить совместимость с выбранной молнией и технологией |
| Низ платья | 30 | Для сильного расклешения способ подгибки пересогласовать |
| Низ базового рукава | 25 | Пробное значение для будущего модуля |
| Сгиб ткани | 0 | Если край действительно раскраивается на сгибе |

Значения не являются прибавками на свободу. Если выбран экспорт без припусков, линия шва сохраняется той же. Полный комплект первого платья включает обтачки; детали обтачек ещё предстоит формализовать и построить.

## Допуски по разным уровням проверки

| Проверка | Рабочий предел | Действие при превышении |
| --- | --- | --- |
| Табличная арифметика реестра | 0.000001 mm; для безразмерных/углов отдельно 1e-10 | Ошибка математического эталона |
| Замыкание координатного контура | 0.01 mm | blocking_error; не скрывать большую щель |
| Аппроксимация кривой для топологии | Геометрическое отклонение ≤0.02 mm, с проверкой бюджета | Уточнить разбиение или ошибка; это не допуск посадки |
| Длина одной численно интегрируемой кривой | Абсолютный бюджет ≤0.02 mm | Уточнить интегрирование; учитывать сумму ошибок всех сегментов |
| Разность швов без посадки | ≤1.0 mm на пару, вычислительный бюджет пары ≤0.1 mm | blocking_error |
| Стороны закрытой вытачки | ≤0.5 mm | blocking_error |
| Окат минус пройма минус заданная посадка | Абсолютный остаток ≤1.0 mm | blocking_error; сама посадка задаётся отдельно |
| Целевые готовые грудь/талия/бёдра | ≤2.0 mm по полному обхвату в рамках методики измерения лекала | blocking_error; не сравнивать с одним bounding box |
| Квадрат при цифровой проверке PDF | 50 × 50 mm, отклонение ≤0.01 mm | Ошибка экспорта |
| Квадрат на бумаге | Каждая сторона 50 ±0.5 mm | Проверить настройки принтера и повторить тест |
| Длинная контрольная линия на бумаге | 200 ±1.0 mm | Проверить масштаб и склейку; квадрат сам по себе недостаточен |

Это **инженерные критерии проекта**, которые предстоит пересмотреть по данным бумажных проверок и макетов. Миллионная доля миллиметра в арифметическом тесте не означает такую точность снятия мерок, ткани или принтера.

## Инварианты полного построения

- Все числа конечны, контуры замкнуты, площадь положительна; нет самопересечений внешнего контура.
- Парные линии измеряются по шву и после предусмотренного закрытия вытачек; отрезки раствора не добавляются к готовому обхвату.
- Талия лифа согласуется с талией юбки отдельно по переду и спинке; совпадения общей суммы недостаточно.
- Контрольные надсечки согласованы по длине парных швов; касательные не образуют непредусмотренных изломов.
- Припуск не меняет линию шва. Offset не уничтожает часть детали и не создаёт необъяснимые островки.
- Детали имеют название, количество кроя, долевую и явное указание сгиба/зеркальности.
- У неэластичного изделия проверяется возможность надеть его: молния и проход кисти при узком рукаве; для юбки отдельно свобода шага.
- Ошибка решателя не возвращает «успех», NaN, пустую деталь или приблизительную производственную выкройку.

Статусы физической проверки и нерешённые вопросы: [VALIDATION_AND_TOILE_LOG.md](VALIDATION_AND_TOILE_LOG.md).
