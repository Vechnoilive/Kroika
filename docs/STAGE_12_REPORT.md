# Отчёт этапа 12 — юбка, топ, блузка, рубашка и жилет

Дата: 2026-09-16.

## 1. Что требовалось

Добавить изделия по одному на общей проверяемой базе, для каждого пройти цикл «формулы → автоматический эталон → код → инварианты», подготовить бумажную/макетную проверку и хранить отдельный `expert/toile status`. Нельзя выдавать автоматический тест за физическую приёмку.

## 2. Что реализовано

- Независимая А-юбка S01–S14 с талиевыми вытачками, передним/задним поясом и молнией сзади.
- Топ без рукавов с круглой горловиной, обтачками и молнией сзади.
- Полуприлегающая блузка с круглой горловиной, длинным одношовным рукавом и молнией сзади.
- Свободная рубашка с длинным рукавом, цельнокроеной передней планкой, стойкой и воротником.
- Жилет без рукавов с передней планкой и обтачками.
- Каталог API/UI с отдельными автоматическими и физическими статусами каждого изделия.
- Динамические мерки, прибавки и поля фасона: интерфейс не показывает пользователю нерелевантные значения.
- Fail-closed проверка пресета и состава компонентов; неизвестное сочетание не маскируется под поддержанное изделие.

## 3. Изменённые области

`pattern-engine` получил формулы юбки, сборку новых компонентов и каталог приёмки. Контракты, JSON Schema и OpenAPI расширены семью типами. Backend отдаёт `/api/v1/garments/catalog`. Frontend получил последовательный выбор изделия, применимые поля и предупреждения. Добавлены `references/stage12`, stage-12 unit/API/UI/E2E проверки, CI и инструкции запуска.

## 4. Тесты

Команда текущего этапа:

```bash
python scripts/verify_stage12.py
```

Она намеренно не запускает тесты предыдущих этапов. Точный результат фиксируется в PR/CI после выполнения команды.

## 5. Экспертная проверка

Автоматически проверены формулы, фиксированный состав деталей, связность/простота контуров, пары швов, допуски, schema/OpenAPI и пользовательский сценарий юбки. Закройщик не проверял бумажные построения, макеты, воротник, окат или посадку ни одного из новых изделий.

## 6. Ограничения и риски

- Все варианты узкие и не являются свободным конструктором фасонов.
- Прибавки и предел 5 мм остаются исследовательскими до подписи специалиста.
- Рубашечный воротник/стойка, одношовный рукав и обработка блузочной горловины требуют приоритетной бумажной проверки.
- A4 PDF диагностический: масштаб нужно измерить минимум на двух принтерах.
- `production_export_allowed=false` для всех семи типов.

## 7. Запуск

```bash
python3 scripts/start_local.py
```

После запуска: `http://127.0.0.1:5173`.

## 8. Gate

**AUTOMATED PASSED / PHYSICAL BLOCKED.** Программная часть пяти новых изделий и отдельные статусы реализованы. Полный gate этапа остаётся заблокированным: `paper_status`, `expert_status` и `toile_status` равны `pending` для каждого изделия; общая историческая регрессия по договорённости пользователя не запускалась.
