# Безопасность и приватность

## Граница доверия

Kroika остаётся локальным однопользовательским приложением без аккаунтов и
авторизации. Локальный запуск и Docker Compose слушают только `127.0.0.1`.
Публиковать backend в локальную сеть или интернет нельзя без отдельной
аутентификации, TLS, rate limiting и пересмотра модели угроз.

Мерки, проекты, ревизии, построения и изображения хранятся в `data/`. Каталог
получает приватные POSIX-права `0700`, файлы базы/фото — `0600`; на Windows
доступ регулируется ACL пользователя. Логи содержат только request ID, метод,
шаблон маршрута, HTTP-статус и длительность — тела запросов, мерки и ключи не
записываются.

Каждое новое JPEG/PNG/WebP декодируется с лимитом 40 мегапикселей,
ориентируется по EXIF и заново кодируется без EXIF/XMP и исходного имени.
Анимация не принимается. Фото, загруженные старой версией, нужно удалить и
загрузить заново, если важно гарантированно убрать прежние метаданные.

## Внешний AI

- `mock` не отправляет данные наружу;
- Qwen получает только выбранные изображения после явного согласия;
- мерки и координаты выкройки в AI-запрос не входят;
- отключённый провайдер нельзя вызвать прямым HTTP-запросом;
- ключи читаются только из окружения backend и не попадают во frontend.

Gemini остаётся отключён. Региональные ограничения и VPN приложением не
обходятся.

## Удаление данных

API поддерживает `DELETE` для проекта, профиля мерок и неиспользуемого фото.
Удаление проекта каскадно удаляет его ревизии и построения, а также удаляет
фото, если на него больше не ссылается другой проект. Резервную копию перед
удалением пользователь создаёт отдельно.

## Автоматический аудит

`python scripts/verify_stage15.py` запускает Ruff, Mypy, Bandit для production
Python-кода, `pip check`, `pip-audit`, `npm audit`, frontend typecheck/build,
accessibility-проверку и mock E2E. Уязвимый `pypdf 6.10.0`, обнаруженный на
этапе 15, заменён на `6.19.0`; Python runtime и npm dependency-аудиты после обновления
не находят известных уязвимостей.

Аудит не делает локальное приложение публичным сервисом и не заменяет
пентест перед сетевым развёртыванием.
