# Отчёт этапа 6 — ядро вычислительной геометрии

Дата: 2026-09-14. Версия приложения: `0.6.0`. Версия ядра: `0.1.0`.

## Результат

В отдельном пакете Pattern Engine реализованы точки, векторы, отрезки, повёрнутые эллиптические дуги, кубические Безье и связные контуры. Добавлены длины, точная ориентированная площадь, границы, пересечения, offset, аффинные преобразования, строгая сериализация и стабильные классы ошибок.

Backend теперь сообщает `kroika-geometry:0.2.0`. При запросе генерации он выполняет детерминированную диагностику ядра, но корректно возвращает `BASE_BLOCKS_STAGE_NOT_READY`: геометрический тестовый прямоугольник не подменяет выкройку.

## Gate

Статус: **PASSED**.

- 36 тестов этапа 6 проходят.
- Пять групп property-based проверок выполняют 420 сгенерированных примеров: площадь при аффинном преобразовании, сохранение расстояний, симметрия пересечения, offset прямоугольника и round-trip эллиптических дуг.
- Проверены `NaN`/`Infinity`, нулевые элементы, разорванные/открытые/самопересекающиеся контуры, коллинеарное перекрытие, касание, схлопывание offset и неподдержанное преобразование дуги.
- Канонический round-trip совместим с `pattern-data.schema.json`; диагностический fingerprint зафиксирован.
- API smoke-test подтверждает, что backend запускает диагностику ядра и не выдаёт тестовую фигуру за выкройку.
- Полный regression suite этапов 2–6 должен выполняться через `scripts/verify_all.py`.

## Ограничения

Пересечения произвольных кривых и общий offset криволинейного контура имеют явный допуск аппроксимации. Ядро блокирует неоднозначный результат, а не исправляет его скрыто. Общие polygon boolean/loop removal не заявлены готовыми.

Этап не содержит формул базовых деталей и не меняет `experimental`-статус методики. Исходный экспертный gate этапа 2 остаётся открытым, поэтому код этапа 7 нельзя считать проверенным построением без ручных эталонов и специалиста.
