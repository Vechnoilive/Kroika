# Методика kroika-gc-woven 0.1.0

Статус: **experimental**. Назначение: формализовать и проверить вычислительные предпосылки первого симметричного платья из неэластичной ткани. Источник блоков — GarmentCode, commit `d449629979028123a5c4dc9e732a2ec19b7fce31`, MIT. Причины выбора и ограничения: [METHOD_RESEARCH.md](METHOD_RESEARCH.md).

## Область текущей спецификации

В этом этапе оформлены скалярные размеры исходных блоков переда, спинки и fitted skirt, распределение вытачек, единицы, рабочие прибавки и инварианты. Это **не полная спецификация всех точек готового лекала**. Не завершены геометрические сопряжения, одношовный рукав, обтачки, перенос вытачек под все вырезы и проверка макетом. До их завершения нельзя объявлять gate исходного этапа 2 пройденным.

Первая проверяемая модель: отрезное по талии полуприлегающее платье без рукавов, круглая горловина, вытачки, А-силуэтная юбка, центральная молния на спинке, обтачки горловины и пройм. Прямая юбка остаётся в общем MVP, но её свобода шага требует отдельной проверки; длина и расширение А-силуэта задаются вручную.

## Входы и единицы

Все длины Kroika — mm, обхваты полные, углы на входе deg, для тригонометрии rad. В исходном GarmentCode длины cm. Перевод числовых констант и входов должен быть однократным; коэффициенты и углы не умножаются на 10.

| Поле Kroika / символ | Измерение или параметр | Источник значения |
| --- | --- | --- |
| `bust` / B | Полный обхват груди по выступающим точкам | Ручное измерение |
| `waist` / W | Полный обхват по отмеченной естественной талии | Ручное измерение |
| `hips` / H | Полный обхват через выступающие точки ягодиц | Ручное измерение |
| `back_bust_arc` / Bb | Задняя часть обхвата груди между согласованными боковыми вертикалями | Ручное измерение, upstream `back_width` |
| `back_waist_arc` / Wb | Задняя часть обхвата талии между теми же вертикалями | Ручное измерение, upstream `waist_back_width` |
| `back_hip_arc` / Hb | Задняя часть обхвата бёдер между теми же вертикалями | Ручное измерение, upstream `hip_back_width` |
| `shoulder_span` / S | Расстояние между внешними концами ключиц по авторскому определению | Ручное измерение, upstream `shoulder_w` |
| `shoulder_slope_deg` / a | Наклон плеча к горизонтали | Ручное измерение угла; не вычислять из обхвата груди |
| `back_neck_to_waist` / Lb | Длина от основания шеи сзади до талии | Ручное измерение, upstream `waist_line` |
| `front_neck_to_waist_over_bust` / Lf | Длина спереди от основания шеи через грудь до талии | Ручное измерение, upstream `waist_over_bust_line` |
| `bust_path_height` / P | Расстояние от плечевого уровня до точки груди по передней линии | Ручное измерение, upstream `bust_line` |
| `bust_vertical_height` / V | Вертикальное расстояние от основания шеи сзади до уровня обхвата груди | Ручное измерение вертикали, upstream `vert_bust_line` |
| `bust_span` / C | Расстояние между точками груди | Ручное измерение |
| `hip_depth` / D | Вертикальное расстояние от талии до уровня бёдер | Ручное измерение |
| `hip_inclination_deg` / h | Наклон боковой линии талия–бедро к вертикали | Ручное измерение угла |
| `armscye_depth` / A | Глубина проймы по определению измерения автора, без прибавки | Ручное измерение |
| Дополнительные для полной выкройки | Ширина основания шеи, верхняя часть руки, запястье, обхват кисти для надевания, длина руки, локоть при рукаве, расстояние между ягодичными точками | Ручные значения; обязательность определяется соответствующим узлом |
| Модельные параметры | Длина юбки от талии, расширение низа, глубины вырезов, длина молнии, ширина обтачек, рукав/бретели | Выбор пользователя, не мерки тела |

Определения основаны на [авторском документе мерок](https://github.com/maria-korosteleva/GarmentCode/blob/d449629979028123a5c4dc9e732a2ec19b7fce31/docs/Body%20Measurements%20GarmentCode.pdf), но инструкции для ручного измерения ещё должны пройти проверку удобства у закройщика. Мерка «ширина груди» или «ширина спины» из привычной таблицы не заменяет дугу обхвата автоматически. Дополнительные снятые мерки хранятся для контроля; ни один вход не заполняется средним значением скрыто.

## Последовательность расчётного блока

1. Проверить полноту, конечность чисел, единицы, положительность длин и допустимость отношений дуг и обхватов.
2. Сохранить исходные мерки неизменными. Отдельно сформировать конструктивные обхваты с подтверждёнными прибавками. Рабочее распределение прибавки между передней/задней дугой — явный параметр, исходно 50/50; оно требует проверки посадки.
3. Вычислить ширины половинок переда/спинки, плечевой наклон, длины и растворы вытачек по реестру. Для отрицательного раствора возвращать ошибку области; не заменять его положительным средним.
4. Для юбки вычислить дуги переда/спинки, боковое заужение и растворы вытачек. Коэффициент задней глубины 1.05 из upstream фиксируется отдельно; разницу длины шва нужно согласовать, а не «съесть» без записи посадки.
5. На этапе 7 задать точки и кривые, построить/закрыть вытачки и измерить готовые линии. Проекционная ширина не равна длине изогнутой талии.
6. Согласовать фактические линии талии лифа и юбки, плечевые и боковые швы, затем пройму и рукав. В первом платье рукав отсутствует; его отсутствие не доказывает готовность рукавного модуля.
7. Модельные преобразования и припуски — последующие операции, со своими проверками. Припуски не добавляются к обхватам тела.

## Реестр и примеры

Человекочитаемый реестр: [FORMULA_REGISTRY.md](FORMULA_REGISTRY.md). Машиночитаемые записи: [formula-registry.json](../references/stage2/formula-registry.json). Три пошаговых расчёта: [REFERENCE_CALCULATIONS.md](REFERENCE_CALCULATIONS.md). Команда их проверки: `python3 scripts/verify_stage2.py`.

В вычислительных профилях прибавки намеренно равны нулю, чтобы проверять перенос исходных формул отдельно от наших рабочих пресетов. Это проверка геометрических заготовок, **не рекомендация шить неэластичное платье с нулевой прибавкой**. Ненулевые прибавки дополнительно проверяются отдельными арифметическими случаями.

## Область применимости и версия

Численно исследованы только три синтетических профиля. Нельзя объявлять интервал между ними клинически или технологически подтверждённым диапазоном фигур. На этапе 7 нужны граничные профили, отсутствие/малый раствор вытачек, разные соотношения переда/спинки и большой раствор; неподдержанные случаи дают понятную ошибку.

Проверяющий скрипт допускает углы только в интервале [0, 40] градусов. Это явно выбранное вычислительное ограничение исследовательских примеров, а не авторский или антропометрически подтверждённый диапазон. Отрицательные длины/растворы и неподдерживаемая нулевая нагрудная вытачка отклоняются без подстановки средних мерок.

Любое изменение коэффициента, способа измерения, правила распределения прибавки или геометрического решателя повышает версию методики. Старые проекты сохраняют прежнюю версию. Зафиксированные здесь числа не заменяют ручной контроль и пробный макет.
