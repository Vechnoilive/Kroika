# Сопряжения модулей фасона

После повторной проверки: движок **0.23.0**, общий реестр **2.0.0**. Рецептуры, допустимые варианты и группы альтернатив находятся в `src/kroika_contracts/design_modules.json`; Python и TypeScript читают один файл. AI получает список вариантов из этого же реестра, но не назначает геометрический модуль и не выдумывает размеры. Пользователь подтверждает конструкцию и размеры.

## Реальная геометрия

| Сочетание | Построение и проверка |
| --- | --- |
| Панели / кокетка юбки + раскрытия | Линии раскрытия распределяются по фактическим панелям. Добавленный раствор учитывается в эффективной длине парного шва. |
| Панели / кокетка + каскад, баска, локальная отделка | Линия крепления разбивается по деталям с непрерывным интервалом; создаются отдельные парные соединения. Сборка распределяется пропорционально длинам. |
| Панели + ремень / кушак | Отдельный аксессуар сохраняет лекала и связь с фактическими фрагментами основы; отсутствие цельной юбки не вызывает исключение. |
| Членение + размещённая строчка / явный контур | Строчка делится по пересечениям, длина сохраняется. Ребро явной дополнительной детали присоединяется к нескольким итоговым срезам с отдельными парными швами и уникальными контрольными линиями. |
| Членение + размещённый карман / накладная панель | Положение отсчитывается в общей системе координат основы. Если деталь целиком помещается на одном фрагменте, используется именно он. Контур и линии пришивания распределяются по фактическим деталям при пересечении швов; накладка остаётся целой. Прорезной вход выполняется после стачивания панелей. Для четырёх размещённых рецептур в редакторе показаны направления размеров. Подробности: [PLACEMENT_EXPANSION.md](PLACEMENT_EXPANSION.md). |
| Панели + скруглённый / асимметричный низ | Каждая панель получает точный участок исходной кривой. Внутренние швы остаются парными. |
| Раскрытия лифа + диагональная / перекрёстная драпировка | Перед разворачивается после раскрытия; сохраняются обе половины контрольных линий. Горловина и обтачка согласуются до раскрытия. |
| Кокетка лифа + драпировка / воротник | Контрольные линии и горловина переходят на фактические фрагменты. У полного переда проверяются крепления обеих половин горловины. |
| Кокетка + рельеф / панели; пересекающиеся смещённые панели | Создаются окончательные ячейки, сохраняются парные интервалы и надсечки; каждая внутренняя граница имеет ровно одну ответную сторону. |
| Замена воротника рубашки | Старая сборка не создаётся; выбранная конструкция получает реальные срезы горловины и отражается в слоях и печати. |
| Несколько оборок / воланов по низу | Порядок списка определяет порядок пришивания. Следующий ярус крепится к свободному краю предыдущего. Поддержаны старые и новые рецептуры полной отделки низа. |
| Подкладка / прокладка / накладной слой + членение | Слой копирует окончательные детали, контрольные линии, количество кроя и внутренние парные соединения. Старый накладной слой юбки сохраняет также присоединённую отделку низа. |

Длины берутся из рассчитанных срезов, а не из названия детали. Проверяется непрерывность перенесённых интервалов, положение линий внутри контура, длина после закрытия вытачек и растворов, припуски и наличие геометрии каждого подтверждённого источника. Линии членения не заменяют контрольные линии молча.

Укорочение слоя юбки с панелями проводится по общей горизонтали для передних и задних панелей юбки, чтобы совпадали их внутренние швы. При фигурном низе это не параллельное смещение всей кривой: длина укорочения отсчитывается от наиболее высокой точки низа всей юбки. Слои с выбранным покрытием дополнительной детали копируют её отдельные лекала; цельнокроеное раскрытие покрывается слоем основы.

## Порядок и сохранение

Панельное членение юбки выполняется до раскрытий. После раскрытий разворачивается перед, затем выполняются конструктивные разрезы и переносы привязок. Отдельные детали строятся по окончательным срезам. Слои создаются после отделки и оформления спинки. Припуски вычисляются последними.

Кнопки «Выше» / «Ниже» сохраняют порядок элементов. Для композиции ключ построения **1.11.0** содержит упорядоченные пары идентификатора источника и модуля. Python и TypeScript формируют одинаковый ключ. При отсутствии новых входов используются прежние версии хеша.

Сохранение проекта, повторное открытие, кеш построения и A4 PDF проверяются через API. После ручной правки и перед SVG/PDF снова проверяются парные срезы, линии раскрытия, драпировка, структурные привязки и соответствие слоя исходным деталям. Потеря линии или рассогласование слоя блокируют результат с конкретной причиной.

## Ограничения конструкции

Готовая рецептура не гарантирует, что любое размещение помещается на конкретных мерках. Линия крепления должна проходить внутри выбранной основы; пересечение раствора вытачки, непарный шов, неподходящая длина и небезопасный припуск требуют изменить размеры или положение.

Для полукругового волана радиус присоединения должен быть больше обычного припуска. Например, срез 3 см при припуске 1 см слишком короткий; это сообщает ошибку припуска с вариантами исправления. Геометрия не заменяется другим углом сектора молча.

Воротники и капюшон на одной горловине, разные манжеты одного рукава, шлица и разрез на одной линии остаются альтернативами. Несколько прямых членений строят общую сетку; кокетка сочетается с плечевым рельефом. Совпадающие линии и пересечение открытого раствора вытачки требуют изменить параметры. Цельнокроеное раскрытие до горловины и срезанный верх под бретели несовместимы; отдельная драпировка допускается. Эти случаи получают сообщение о конфликте конструкций, а не ложное сообщение об отсутствующем модуле.

Число деталей, симметрия и обязательные размеры проверяются по конкретной рецептуре. Неизвестная дополнительная деталь требует явного контура и крепления или выбора известной конструкции. Произвольный текст AI не превращается автоматически в готовое лекало.

Перенос талиевой вытачки в боковой шов предлагается только для прилегающей и полуприлегающей основы: у свободного и объёмного лифа талиевая вытачка отсутствует. Плечевой рельеф также требует талиевую вытачку. У рубашки отдельная стойка, капюшон, фигурный плоский или шалевый воротник заменяют штатную стойку и отлёт с сохранением планки. Это ограничения конструкции, а не отсутствие всех модулей драпировки или воротников.
