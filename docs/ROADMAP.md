# Дорожная карта — 22 этапа

Этапы 1–15 образуют первый исследовательский release candidate. Этапы 16–20 добавлены после решения строить фасон по фотографии не как ближайший шаблон, а через проверяемый конструктивный план. Этап 21 закрывает первый ограниченный набор настоящих топологических преобразований. Этап 22 добавляет способ честно записать физические проверки конкретной генерации; реальные проверки и пилот всё ещё должны провести люди.

## Ключевые зависимости

- Этап 1 не требует написания приложения и не может получить PASSED без согласования PRD.
- По поручению пользователя рабочие ответы этапа 2 выбраны разработчиком. Фактическая экспертная проверка остаётся отдельным условием: расчёт разработчика не считается подписью закройщика.
- Геометрические операции этапа 6 не разрешают скрытые формулы. Геометрические коэффициенты этапа 7 зафиксированы, описаны как experimental и не открывают производственный экспорт.
- По продуктовому решению Qwen — единственный внешний провайдер в интерфейсе этапа 11; mock остаётся безопасным default без ключа. Gemini сохранён выключенным адаптером, региональные ограничения не обходятся.
- Ни schema tests, ни геометрические тесты, ни успешный PDF не доказывают посадку. Бумажная проверка и макет остаются отдельными условиями.
- Движок возвращает успешный диагностический PatternData только после сборки всех деталей и безопасных линий среза; производственный экспорт остаётся запрещённым до физической печати, проверки макета и методики.

Автоматические части этапов 15–17, 20–22 и ограниченные модули этапов 18–19 реализованы. Этап 21 поддерживает только прямую парную кокетку юбки, равные панели и частичный перенос передней талиевой вытачки; фигурные/асимметричные членения, полное закрытие вытачки и сложные многослойные узлы остаются заблокированы. Журнал этапа 22 не заменяет реальные измерения и подпись специалиста. Live-внешний AI E2E этапа 11, физический gate этапа 9, реальный quality-набор этапа 10, пилот с тётей, макеты всех изделий и экспертные gates открыты, пока люди не внесут настоящие записи. Поэтому приложение является исследовательским release candidate, а не production-системой для раскроя ткани.
