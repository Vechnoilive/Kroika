# Отчёт по этапу 9

Дата: 2026-09-15.

## Результат

Реализованы припуски по типам участков, отдельные линии среза всех шести деталей, парные надсечки, единый SVG и диагностический PDF A4 в масштабе 1:1. PDF содержит страницу-инструкцию, карту листов, физический квадрат 50×50 мм, 10-мм поля и нахлёст, обозначения листов и метки совмещения.

Движок обновлён до `kroika-geometry 0.5.0`, backend и frontend — до `0.9.0`. Старые документы схемы v1 остаются читаемыми; новые результаты содержат `edge_allowances`, `print_layout`, заполненный `cutting_contour` и `match_id` надсечек.

## Безопасность для пользователя

- неполные, отрицательные или нечисловые припуски блокируют построение;
- сгиб допускает только 0 мм;
- самопересекающаяся линия среза не исправляется скрыто и не экспортируется;
- SVG не использует скрипты и внешние ресурсы;
- русские подписи PDF печатаются встроенным Unicode-шрифтом;
- файлы и HTTP-заголовки явно отмечают диагностический режим;
- `production_export_allowed=false` не меняется от успешного цифрового теста.

## Автоматический gate

Отдельная команда `python scripts/verify_stage9.py` запускает только проверки этого этапа:

- соответствие каждого припуска исходному `segment_id`;
- простоту, замкнутость и конечность шести линий среза;
- наличие двух совместимых надсечек для каждой из десяти пар швов;
- безопасный единый SVG и квадрат 50×50 мм;
- A4 MediaBox, карту, подписи, масштаб 1:1, покрытие листами и 10-мм нахлёст;
- понятный адаптивный экран печати и обработку ошибки скачивания;
- production-сборку frontend и HTTP smoke-test обоих экспортов.

CI веток `codex/**` и `main` также запускает только `verify_stage9.py`. Полная историческая регрессия остаётся в `verify_all.py` и запускается по отдельному решению пользователя.
